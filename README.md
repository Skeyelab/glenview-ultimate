# Glenview Ultimate Monorepo

## Prerequisites
- Node.js 20.11 or newer
- npm 10

## Getting Started
```bash
npm install
npm run dev
```

## Turbo Commands
- `npm run dev` – runs workspace dev servers in parallel
- `npm run build` – builds all workspaces
- `npm run lint` – runs lint tasks across the monorepo
- `npm run typecheck` – runs TypeScript checks across the monorepo
